SHARESAFE COMPANION

Cover a webpage.
Share as usual.

Install once in Chrome. Direct Blur is the default. Your masks blur real webpage pixels locally and in shares that capture the rendered webpage.

  1. In Chrome’s address bar, enter chrome://extensions.
  2. Turn on Developer mode, then click Load unpacked.
  3. Select the ChromeExtension folder containing this guide and manifest.json. If using a zip, extract it first. If using the native build, a copy is inside ShareSafe.app → Contents → Resources → ChromeExtension. The current menu-bar app does not open the installation folder for you.
  4. Pin ShareSafe Companion from Chrome’s Extensions menu.
  5. Open a website. Click ShareSafe or press ⌘⇧H (Ctrl+Shift+H on Windows/Linux), then click an element to cover it.

Your covers, your controls

Style: Blur / Solid chooses the style for new masks. Hide area draws a fixed viewport rectangle. Hide element follows content as it moves. Escape or Done ends selection and leaves covers in place. Undo removes the latest; Clear restores everything.

Use a normal webpage

Chrome’s settings, new-tab pages, Web Store, built-in viewers and browser controls cannot be masked. To try the offline demo, enable Allow access to file URLs in the extension details. The shortcut can be changed at chrome://extensions/shortcuts.

Covers reset on navigation/reload. Replaced page elements need selecting again. If page fullscreen blocks the toolbar, ShareSafe conceals the source while returning to the normal page, retaining your covers. Area masks switch to solid when page dialogs/popovers open. Close page modal dialogs to use the toolbar. Frame contents have limits. This companion works independently of the desktop app; it does not detect sharing or control meeting apps. Check the receiver’s view before a sensitive share. Read the full guide.
